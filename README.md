# 🚀 AlgoRythmX – Advanced Algorithm & OS Visualizer

AlgoRythmX is a comprehensive web-based platform that visualizes algorithms and core operating system concepts through interactive and intuitive animations. It is designed to help students understand complex topics in Data Structures and Operating Systems visually and creatively.

---

## 🌟 Key Features

### 🔄 Sorting Algorithms
- Bubble Sort
- Selection Sort
- Insertion Sort
- Merge Sort
- Quick Sort
- Heap Sort

### 🔍 Searching Algorithms
- Linear Search
- Binary Search

### 🧠 Graph Algorithms
- Breadth First Search (BFS)
- Depth First Search (DFS)

### 💻 CPU Scheduling
- First Come First Serve (FCFS)
- Shortest Job First (SJF)
- Round Robin

### 🧮 Memory Allocation
- First Fit
- Best Fit
- Worst Fit

### 💾 Disk Scheduling
- FCFS
- SSTF
- SCAN

### 📄 Page Replacement
- FIFO
- LRU
- Optimal

### 🎨 Computer Graphics Algorithms
- DDA Line Drawing
- Bresenham Line Algorithm
- Midpoint Circle Algorithm
